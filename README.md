# Pure Scents design prototype

An unofficial design prototype prepared for the owner of Pure Scents. It is not the live store and no orders can be placed.

- All product names, prices and sizes come from the public Pure Scents catalog.
- Labels are generated. Store photography and checkout are part of the Shopify build.
- This site is excluded from search engines and is not linked from purescents.shop.

Prepared by Marcus Cooper, October 2026.
